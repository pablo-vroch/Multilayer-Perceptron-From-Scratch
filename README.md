# Multilayer Perceptron From Scratch

An independent scientific computing project exploring the mathematical foundations and numerical implementation of artificial neural networks.

I derived the backpropagation algorithm from first principles using tensor calculus and implemented a fully vectorized multilayer perceptron in Python using NumPy, without machine learning frameworks.

**Key features:**
- Configurable multilayer neural network architecture.
- Forward propagation and backpropagation implemented from scratch.
- Vectorized tensor operations and NumPy broadcasting.
- ReLU activation functions and gradient descent optimization.
- Object-oriented design with support for batch processing.
- Experimental approximation of mathematical functions.

**Project status:** Experimental implementation. Training convergence and numerical stability require further improvement.
